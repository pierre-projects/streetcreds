# Demo photos

Real photos for the populated demo set in `../demo.ts`, used only when `VITE_MOCK_DEMO=true`.

Name each file after a report id, for example `demo-pothole-1.jpg` or `demo-sidewalk-curb.webp` (jpg, jpeg, png or webp). A report with no photo here shows a drawn placeholder. Git ignores every photo here, so they stay on this laptop and never reach the live site. Use only photos you took or have the rights to.
